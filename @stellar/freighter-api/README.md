# Varial SDK

This package builds a wrapper around the messaging system used to interact with
the Varial web extension. Client applications can install this package from npm
and then integrate with Varial using dev-friendly methods like `getAddress`.

```
npm install @stellar/varial-sdk
```

`@stellar/varial-sdk` was previously published as `@stellar/freighter-api`.
Dapps already using `@stellar/freighter-api` keep working; new methods are only
added here.

For instructions on how to integrate with Varial, visit:
https://docs.varialwallet.com/
